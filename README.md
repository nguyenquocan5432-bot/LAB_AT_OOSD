## Hướng dẫn chạy

1. Tải repository bằng Code → Download ZIP hoặc git clone.
2. Chạy script SQL trong thư mục của bài.
3. Mở solution bằng Visual Studio.
4. Cấu hình kết nối cơ sở dữ liệu.
5. Chọn project khởi động và nhấn F5.

Hướng dẫn riêng được ghi trong README của từng project.
