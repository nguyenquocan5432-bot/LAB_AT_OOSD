# LAB_AT_OOSD

Bài thực hành môn Phân tích thiết kế phần mềm hướng đối tượng.

## Danh sách bài thực hành

| Bài | Nội dung |
| --- | --- |
| [LAB1](LAB1/) | Đặc tả Use Case và mô hình UML |
| [LAB2](LAB2/Quan_Ly_Thu_Vien/) | Quản lý thư viện |
| [LAB3](LAB3/) | Quản lý khách sạn |
| [LAB4](LAB4/) | Hệ thống e-Shopping |
| [LAB5](LAB5/) | Quản lý công ty du lịch Văn Hóa Việt |

## Công nghệ sử dụng

- C# WinForms
- SQL Server
- UML
- Visual Studio

LAB2 và LAB3 sử dụng .NET 10.
LAB4 và LAB5 sử dụng .NET Framework 4.7.2.

## Hướng dẫn chạy

1. Tải repository bằng Code → Download ZIP hoặc git clone.
2. Chạy script SQL trong thư mục của bài.
3. Mở solution bằng Visual Studio.
4. Cấu hình kết nối cơ sở dữ liệu.
5. Chọn project khởi động và nhấn F5.

Hướng dẫn riêng được ghi trong README của từng project.
